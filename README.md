# 希心之光 光島生活故事整合版

本版延續生命數字島原創探索版，新增光的課程島生活故事。解壓後請將全部檔案一起部署至原Netlify專案。

## 光島新增內容

- 三幕主線保留；完成前兩幕後，在第三幕選讀「身體照顧」「人際關係」「送光與祝福」。選讀不要求全部完成。
- 第二幕加入創作者對家庭情緒責任的反思，原創作者長期修習感受保留。
- 生活故事依既有貼文整理並標日期，小光的回應為網站敘事。
- 送光篇可以選擇祝福自己、在乎的人或牽掛的地方；不收集姓名，不上傳互動內容。畫面陪伴訪客整理關懷與祝福，不判定送光效果。
- 正式課程介紹加入光的觀想、送光及班級傾聽與陪伴，日期、費用、教師資格及報名資訊仍為待補。
- 素材來源與編輯範圍請讀 CONTENT_SOURCES.md；本次測試請讀 TEST_REPORT.md。

以下為保留的生命數字島使用說明。

本版以「希心之光_生命數字島_解讀修正版.zip」為基礎，更新生命數字島的內容與閱讀方式，保留其餘網站內容。

## 部署

解壓縮ZIP，將包含index.html、app.js及其他檔案的整個資料夾上傳至原Netlify網站的手動部署區。不要只上傳HTML，也不要只上傳新增的生命數字模組。這是已完成的靜態網站，不需要npm安裝、build指令或API金鑰。延續原Netlify專案即可維持原網址；本次未代為上線。

本機預覽請在資料夾內執行 `python3 -m http.server 8000`，再開啟 http://localhost:8000 。不要用file://雙擊HTML判斷題庫載入是否正常。

## 這次的閱讀方式

1. 輸入生日，先看生命歷程數與生日數。
2. 閱讀兩個數字之間的關係，選擇「很貼近我／有一部分／目前不像我」。
3. 可選擇最近想理解的生活主題，看看提問與小練習。
4. 需要時自行展開完整鑽石圖，閱讀其餘11個生日指標。
5. 姓名探索提供7個指標；尚未填生日時先提供5個，理性數與成熟數在補齊生日後顯示。
6. 數字小徑提供0至9的原創生活提問，不需先輸入生日。

同一組不分先後的數字有一段關係文字，共45組，連同位置分工可涵蓋81種生命歷程數／生日數組合。這些是原創象徵解讀，不是書中原有的組合定律。兩個主要位置的說明會分開顯示，訪客可自行判斷是否貼近經驗。

## 保留與調整

- 保留最新版本已修正的日期有效性、閏年、中間名、理性數、高峰年齡區間，以及11／22化約標記。
- 生日及姓名介面固定使用鑽石算法，不再讓訪客切換另一套姓名對照表後混讀同份報告。
- 《原數力量》只提供特質可以發展的編輯啟發；不評定訪客處於哪個成熟階段。
- 本版沒有混入《時間秘數》的流年／流月，或《生命靈數全書》的出生九宮格規則；未提供預測或姓名補缺數。
- 移除舊生命數字介面的大段職業、正負特質、四階段與電影角色資料，重新寫成生活提問、不同位置的解讀及練習。
- 計算依據及參考資料保留在島內可展開的說明中；原創文案不冒充原書論述。
- 不加性格評分、準確率、靈性高低或成熟認證。
- 生日、姓名與訪客選擇只存目前頁面記憶體，不寫入localStorage，也不上傳。離開島嶼返回時可保留；重整或使用清除按鈕即清除相應資料。

## 新增檔案

- numerology.js：分層閱讀、輸入驗證、關係文字、情境、清除及互動。
- numerology-content.js：0～9、45組關係、20個位置語境、3個生活主題的原創內容。
- numerology-diagram.js：沿用原鑽石圖幾何，標示改為一般指標名稱；可點擊與鍵盤操作。
- numerology.css：限生命數字島使用的樣式，不更動其餘五島。

其他必要檔案包括index.html、app.js、原站style.css與utilities.css、光島light-journey.js／css、light-levels.json及netlify.toml。所有檔案都需一起部署。
